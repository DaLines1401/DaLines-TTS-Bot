# 🤖 Discord Thai TTS Bot (บอทอ่านข้อความเสียงภาษาไทย)

บอทอ่านข้อความเสียงภาษาไทยสำหรับ Discord คุณภาพระดับพรีเมียมด้วย **Microsoft Edge Neural TTS** (เสียงธรรมชาติ ไม่แข็งทื่อเหมือน Google แปลภาษา) เหมาะมากสำหรับคนที่ไม่มีไมค์ หรือไม่อยากเปิดไมค์ แค่พิมพ์ในห้องแชท บอทก็จะอ่านออกเสียงให้เพื่อนในห้องเสียงฟังทันที!

---

## ✨ จุดเด่นและฟังก์ชันเด่น

- 🎙️ **เสียงภาษาไทยสมจริงเป็นธรรมชาติ**: ใช้เสียงพรีเมียม `th-TH-PremwadeeNeural` (หญิง) และ `th-TH-NiwatNeural` (ชาย)
- ⚡ **ไม่ต้องลง FFmpeg เอง**: มี FFmpeg แบบ Portable ฝังมาพร้อมกับ Python Library แล้ว รันบน Windows ได้ทันทีโดยไม่ต้องแก้ Environment Variables หรือ PATH
- ⏳ **ระบบคิวเสียงอัจฉริยะ (Audio Queue)**: จัดคิวให้อ่านทีละข้อความอย่างเป็นระเบียบ ไม่แย่งกันพูด และไม่เกิดข้อผิดพลาดของ Discord Voice
- 💬 **อ่านอัตโนมัติ (Auto-TTS)**: เรียกบอทเข้าห้องเสียงปุ๊บ ห้องข้อความนั้นจะกลายเป็นห้องอ่านเสียงทันที พิมพ์อะไรบอทก็อ่านให้
- 🧹 **กรองข้อความฉลาด (Smart Text Cleaner)**:
  - ลิงก์ `https://...` จะถูกอ่านเป็น *"ส่งลิงก์"*
  - Mention สมาชิก `<@username>` จะแปลงเป็นชื่อคนนั้น
  - ข้อความยาวเกินกำหนดจะตัดให้อัตโนมัติ ป้องกันสแปม
  - ตัดโค้ด, ตัดแท็กสปอยล์, จัดการอีโมจิ
- 🚪 **ออกจากห้องอัตโนมัติ (Auto Disconnect)**: เมื่อไม่มีคนอยู่ในห้องเสียง บอทจะออกเองเพื่อประหยัดทรัพยากร
- 💻 **รองรับ Slash Commands เต็มรูปแบบ**: ควบคุมง่ายผ่านเมนูคำสั่งของ Discord

## 📋 คำสั่งทั้งหมด (Slash Commands)

| คำสั่ง | รายละเอียด |
| :--- | :--- |
| `/join` | เรียกบอทเข้าห้องเสียงที่คุณอยู่ และผูกห้องข้อความนี้เพื่ออ่านอัตโนมัติ |
| `/leave` | ให้บอทออกจากห้องเสียงและเคลียร์คิวทั้งหมด |
| `/say [ข้อความ]` | สั่งให้อ่านข้อความทันที (ใช้ได้ตลอด) |
| `/bind [ห้อง]` | ผูกห้องข้อความสำหรับการอ่านอัตโนมัติ |
| `/unbind` | ยกเลิกการอ่านอัตโนมัติในห้องนี้ |
| `/voice` | เปลี่ยนเสียงพากย์ (เปรมวดี หญิง / นิวัฒน์ ชาย / ภาษาอังกฤษ) |
| `/speed` | ปรับความเร็วเสียง (ช้า -20% / ปกติ +0% / เร็ว +20% / เร็วมาก +40%) |
| `/name_toggle` | สลับเปิด/ปิดการอ่านชื่อคนพิมพ์ (เช่น *"กานต์ พูดว่า: สวัสดี"* หรือแค่ *"สวัสดี"*) |
| `/skip` | ข้ามข้อความที่กำลังอ่านอยู่ |
| `/clear` | ล้างคิวข้อความที่รออ่านทั้งหมด |
| `/twitch_listen [ช่อง]` | ดึงแชท Twitch มาอ่านในห้องเสียง (มีตัวเลือก DaLines, JxoExe, PaulJaw หรือพิมพ์ชื่อช่องเอง) |
| `/twitch_stop` | หยุดการอ่านแชทจาก Twitch |
| `/status` | ดูสถานะปัจจุบันของบอท |
| `/help` | ดูวิธีใช้งานคำสั่งทั้งหมด |

## 🛠️ ขั้นตอนการสร้างบอทและนำไปใช้งาน (Step-by-Step)

### ขั้นตอนที่ 1: รับ Token บอทจาก Discord Developer Portal

1. เข้าไปที่ [Discord Developer Portal](https://discord.com/developers/applications) แล้วล็อกอินบัญชี Discord
2. กดปุ่ม **`New Application`** ด้านขวาบน และตั้งชื่อบอทของคุณ เช่น `TTS Voice Bot`
3. ไปที่เมนู **`Bot`** แถบด้านซ้าย
4. ใต้ชื่อบอท จะมีส่วนของ **Token** ให้กดปุ่ม **`Reset Token`** (หรือ `Copy Token`)
   > ⚠️ **คำเตือน**: Token นี้เป็นความลับ ห้ามนำไปแชร์ให้ใครเด็ดขาด!
5. เลื่อนลงมาที่หัวข้อ **`Privileged Gateway Intents`**:
   - ✅ ติ๊กเปิด **`Message Content Intent`** (**สำคัญมาก!** ถ้าไม่เปิด บอทจะมองไม่เห็นข้อความที่พิมพ์ในห้องแชท)
6. กดปุ่ม **`Save Changes`** ด้านล่าง

---

### ขั้นตอนที่ 2: เชิญบอทเข้าสู่เซิร์ฟเวอร์ Discord ของคุณ

1. ในหน้า Developer Portal ให้ไปที่เมนู **`OAuth2`** -> **`URL Generator`**
2. ในช่อง **`SCOPES`** ติ๊กเลือก:
   - ✅ `bot`
   - ✅ `applications.commands`
3. ในช่อง **`BOT PERMISSIONS`** ติ๊กเลือก:
   - ✅ `Send Messages` (ส่งข้อความ)
   - ✅ `Read Message History` (อ่านประวัติข้อความ)
   - ✅ `Add Reactions` (ใส่อีโมจิปฏิกิริยา)
   - ✅ `Connect` (เข้าห้องเสียง)
   - ✅ `Speak` (พูดในห้องเสียง)
4. คัดลอกลิงก์ที่ช่อง **`GENERATED URL`** ด้านล่างสุด นำไปเปิดในเว็บเบราว์เซอร์ แล้วเลือกเซิร์ฟเวอร์ Discord ของคุณเพื่อเชิญบอทเข้า

---

### ขั้นตอนที่ 3: ใส่ Token ในโปรเจกต์

1. เปิดไฟล์ `.env` ที่อยู่ในโฟลเดอร์โปรเจกต์นี้
2. แทนที่ `your_bot_token_here` ด้วย Token ของคุณ:
   ```env
   DISCORD_TOKEN=MTE5OT... (วาง Token ที่คัดลอกมาตรงนี้)
   ```
3. บันทึกไฟล์ `.env`

---

### ขั้นตอนที่ 4: เริ่มรันบอท

คุณสามารถเปิดใช้งานบอทได้ง่ายๆ ผ่าน 2 วิธี:

#### วิธีที่ 1: ดับเบิลคลิกไฟล์ (แนะนำ)
- ดับเบิลคลิกที่ไฟล์ **`run.bat`** ได้ทันที

#### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```powershell
.venv\Scripts\python.exe bot.py
```

เมื่อบอทออนไลน์ จะแสดงข้อความในหน้าต่างคอนโซล:
```text
==================================================
 บอทพร้อมทำงานแล้ว: YourBotName
 ชวนบอทเข้าห้องเสียงด้วยคำสั่ง: /join
==================================================
```

## 🎮 เริ่มใช้งานใน Discord

1. เข้าห้องเสียงที่คุณต้องการใน Discord
2. ในห้องพิมพ์แชท ให้พิมพ์คำสั่ง:
   ```text
   /join
   ```
3. บอทจะเข้ามาในห้องเสียง และผูกห้องพิมพ์แชทนั้นเข้ากับระบบอ่านเสียง
4. พิมพ์ข้อความอะไรก็ได้ในห้องแชท บอทจะอ่านออกเสียงให้เพื่อนในห้องเสียงฟังทันที!
